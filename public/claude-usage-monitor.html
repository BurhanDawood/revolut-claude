Stretching Your Usage
💬
Start fresh conversations
Long threads consume more tokens as Claude re-reads history. Start new chats for new topics.
🕐
Avoid peak hours
1–7 PM BST (5–11 AM PT) has reduced limits. Schedule heavy dev sessions for evenings.
📋
Use Projects for context
Project descriptions count once, not per message. Keep system prompts in project settings.
⚡
Sonnet over Opus
Sonnet 4.6 has higher limits than Opus. Use Opus only for complex analysis tasks.
